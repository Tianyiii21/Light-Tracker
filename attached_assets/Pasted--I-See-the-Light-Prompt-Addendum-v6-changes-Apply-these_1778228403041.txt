## FIX 2 — CANVAS MUST COVER FULL SCREEN INCLUDING BOTTOM

All canvas elements throughout the app must use `position: fixed` instead
of `position: absolute`. Fixed positioning ensures the canvas covers the
entire viewport including the bottom safe area on iPhone, regardless of
content height or scroll state.

```css
canvas {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  z-index: 0;
}
```

In JavaScript, always size canvas to the full window:

```javascript
function resizeCanvas(canvas) {
  canvas.width = window.innerWidth;
  canvas.height = window.innerHeight;
}
```

Call this on load and on every window resize event. After resizing,
immediately redraw the background gradient so there is no flash of
black or white.

The background gradient on every canvas must extend from y=0 all the
way to the full canvas height — no gaps at top or bottom.

## FIX 3 — RESTORE GENTLE STAR BLINKING

Stars are currently completely static. Restore a slow, gentle pulse to
every star using a sine wave. This must be implemented in the canvas
animation loop — not with CSS animations.

Each star object must have:

```javascript
{
  x: ...,
  y: ...,
  radius: ...,
  phase: Math.random() * Math.PI * 2,   // unique starting phase per star
  speed: 0.004 + Math.random() * 0.006  // slow pulse: 4–8 second cycle
}
```

In the animation loop, update each star every frame:

```javascript
star.phase += star.speed;
star.opacity = 0.2 + 0.25 * Math.sin(star.phase);

ctx.beginPath();
ctx.arc(star.x, star.y, star.radius, 0, Math.PI * 2);
ctx.fillStyle = `rgba(220, 215, 200, ${star.opacity})`;
ctx.fill();
```

Rules:
- Opacity ranges between 0.20 (dim) and 0.45 (soft glow) — never fully
  invisible, never bright
- Each star has a different phase offset so they never pulse in sync
- Each star has a slightly different speed so the sky feels organic
- The overall effect: a slow breathing night sky, barely perceptible
  but alive and warm
- Stars must NEVER be fully static
- Stars must NEVER react to user typing, tapping, or any input event
- Star opacity must ONLY be driven by the sine wave above

Apply this star behaviour on Screens 3 and 4 wherever stars appear.
